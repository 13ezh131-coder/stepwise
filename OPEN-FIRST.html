STEPWISE

Рабочий проект с каталогом пошаговых инструкций, регистрацией, редактором и базой SQLite.

  1. Распакуйте всю папку проекта.
  2. Установите Node.js версии 22.13 или новее, если его ещё нет.
  3. Откройте START.cmd двойным щелчком и оставьте появившееся окно открытым.
  4. Перейдите на http://localhost:4173/.

Исходники на GitHub

Для автоматических проверок откройте TEST.cmd. Чтобы посмотреть таблицы базы после первого запуска — VIEW-DATABASE.cmd.

Генерация с ИИ требует собственного API-ключа в .env по образцу .env.example. Каталог, регистрация и инструкции работают без него.

Архив для преподавателя содержит текущую базу. При скачивании исходников с GitHub база создаётся из стартовых примеров. Аккаунты в отдельных копиях не синхронизируются.
