Как запустить у себя

1. Распаковать проектПолучить ZIP и извлечь папку STEPWISE целиком. Один index.html не заменит весь проект.
2. Установить Node.js 22.13 или новееЕсли он уже установлен, повторно устанавливать не нужно.
3. Открыть терминал в папке STEPWISEВ этой папке находятся server.js и package.json. Выполнить команду ниже.
npm start
4. Открыть сайтhttp://localhost:4173/ — адрес на том компьютере, где запущен сервер. Терминал оставить открытым. Для остановки нажать Ctrl+C.
Как запустить проверки?

В терминале в папке проекта выполнить npm test. Тест использует отдельную временную базу и не меняет ваши инструкции. Он не вызывает платную нейросеть.

Будет ли работать ИИ у преподавателя?

Для ИИ нужен собственный файл .env с ключом AnyModel по образцу .env.example. После настройки сервер нужно перезапустить. Без ключа каталог и инструкции работают. Платная генерация ИИ не входила в эти автоматические проверки.

Что делать с предупреждением SQLite?

На Node.js 22 возможно сообщение ExperimentalWarning. Это предупреждение о статусе встроенного модуля SQLite, а не сообщение о падении сайта.

Что показать преподавателю

  1. Открыть главную страницу, выбрать категорию и инструкцию.
  2. Пройти несколько шагов и показать прогресс.
  3. Нажать на аватар, зарегистрироваться и создать свою инструкцию с двумя шагами.
  4. Показать профиль и статистику; выйти и зарегистрировать второй аккаунт — у него свои публикации.
  5. Перезапустить сервер и показать, что инструкция сохранилась.
  6. Открыть эту страницу и объяснить роль сервера и базы.

Git и GitHub — в чём разница и что осталось?

Git хранит историю версий прямо в папке проекта — это уже сделано. GitHub позволяет передать ссылку на исходники через интернет. Для загрузки ещё нужен адрес вашего GitHub-репозитория и доступ к нему. Дизайн можно продолжать менять и затем сохранять новую версию.
